# Fleet Management System

A web-based Fleet Management System developed using Python and Flask.

## About the Project

The Fleet Management System helps manage vehicles, drivers, maintenance schedules, routes, and vehicle tracking through a simple web interface.

## Features

- Vehicle Management
- Driver Management
- Maintenance Scheduling
- Route Management
- Automatic Distance Calculation
- Estimated Travel Time Calculation
- Route Map using OpenStreetMap
- Vehicle Location Tracking
- Dashboard with Fleet Statistics

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- OSRM
